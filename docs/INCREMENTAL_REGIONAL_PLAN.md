Every original frozen reduced factor has one stable ordinal owner. Active and sealed messages jointly retain a disjoint, complete factor cover. Initially, genuinely private variables are projected by one-input exact DP; domain-one axes use immutable numeric aliases. Every active message represents the exact conditional minimum of its owned factors. A scheduled merge consumes all active messages containing its pivot, removes that pivot, and retains the other union variables as its boundary. It preserves precise high/low values and recursive backpointers and independently minimizes directed-down lower tables. Duplicate ownership and stale-bucket checks guard replacement; full cover audits run at initialization and finalization. There is no legacy-neighborhood-affinity ranking.

The original seed is mapped through the quotient. Finite-support propagation completes auxiliaries, with an auxiliary-only conditional exact fallback if needed. Frozen, original encoded and canonical objectives must agree. A completed merge can reconstruct a conditional joint candidate at the incumbent boundary; only strict canonical improvement changes U. Candidate reconstruction is skipped when the new bound already certifies the existing validated incumbent. L is the maximum of previously published valid downward sums of active and sealed message minima. An L>U contradiction is an error, never silently clamped. No separate Global restart is called.

The controller caches complete variable buckets in an incidence map and an ordered queue. It prioritizes the smallest output separator, then estimated union-table work and stable variable rank. Within a bounded shortlist having the same smallest separator size, shared-variable min-marginal conflict divided by estimated work chooses the next bucket. Conflict is a scheduling heuristic, not a promised global bound improvement. Zero-score buckets still progress, and affected candidates are refreshed after a merge. With sufficient resources all boundaries disappear and L=U at the exact endpoint. Fixed resource limits can return an unfinished valid certificate.

The v6 DP kernel decodes each output boundary once, enumerates its sorted internal assignments, and computes each child cell index once for both exact and lower-bound arithmetic. It records a canonical full-union backpointer only on strict improvement. Child summation order, downward arithmetic and first-tie semantics are preserved. Global already uses the analogous separator-outer elimination structure.

Each merge preflights union assignments, output cells and retained numeric table/backpointer slots. Optional min-marginal caches are evicted if they would prevent admission of required DP output. The numeric slot cap excludes Java object metadata and is not a JVM peak-memory guarantee. The time limit is a soft scheduling limit after bootstrap, not a hard phase or JVM deadline. Whole planning comparisons include preparation, seed, DP, scoring, validation, tracing and emission.
