# Pre-builder AST/HOP snapshot evidence

`PrebuilderSnapshot.capture(program, frozenSources)` is a test-only, read-only projection of a compiled `DMLProgram`. Call it immediately before `NeutralPlacementGraphBuilder.buildAnalysis(program)`. It reads parser statement blocks and HOP inputs directly; it does not consult the placement graph, candidate metadata, selector, or planner-derived privacy.

The snapshot records ordered main and named-function blocks, including nested `if`, `else`, `while`, `for`, and function bodies. Each block has its source location and `recompileOnce` bit. Each root retains its role and position (`body`, `predicate`, `from`, `to`, `increment`, or function-call `output`). Every reachable HOP retains its ID, class, operation, name, data/value types, shape, recompile bit, source location, and each input occurrence with its exact index. Function declarations include input/output parameter names. Calls that remain as `FunctionOp` HOPs retain input/output variable-name arrays, including `null` when the compiler provides no names; calls inlined during parser validation retain the statement-level call boundary and every formal, bound, and actual input/output mapping. B-07 exposed the latter case: the initial HOP-only call assertion failed, and the snapshot now captures the surviving inlining boundary explicitly. The verifier resolves full imported-function keys, including names containing `/`.

The caller must supply `ExternalSource(origin, privacy, partition)` keyed by the exact FEDERATED HOP ID. A missing source causes capture to fail. Fixture tests explicitly supply `PRIVATE_AGGREGATE` for B-11; no privacy value is inferred from the production planner. Other tests exercise B-04 (branch), B-07 (function and call), B-09 (explicit recompile clone), and B-18 (nested control). `PrebuilderSnapshotVerifier.assertMatches` independently traverses raw parser blocks and HOP references and rejects a snapshot whose block paths, roots, HOP IDs, ordered input occurrences, function signatures, HOP/inlined calls, shapes, or recompile flags diverge. A mutation test removes a raw AST block and verifies rejection.

This snapshot is an input-authority check, not a proof of feasible placement plans. In particular, it does not infer transfer legality or certify all runtime behavior. A full certification cell should persist the snapshot and its frozen source metadata alongside production P/E exports, then compare their HOP/CFG authorities before plan-set comparison.
